== Description ==

Flexify is a modern, responsive, multipurpose WordPress theme by ThemeREX (https://themerex.net/). It has built-in support for popular page builders (Elementor and the block editor), a posts slider with swipe gestures, and is SEO- and Retina-ready. The unique system of inheritance and override options lets you set individual parameters for different sections of your site and for the supported plugins.

Theme homepage and Pro version: https://themerex.net/downloads/flexify-100-elementor-wordpress-theme/

= Free version features =

* Fully responsive, mobile-friendly layout, Retina-ready
* Elementor and block editor (Gutenberg) support, wide and full-width blocks
* Customizable front page with ready-made sections: title, features, about, team, testimonials, blog, products, subscribe, map, contacts
* Theme options in the WordPress Customizer: colors, typography, layouts, sidebars, header and footer variants
* Custom logo, custom header, custom background, custom menus, featured images
* Post formats (video, audio, gallery, quote, link, and more) and threaded comments
* Sidebar layouts (left, right, none) and footer widget areas
* Full-width and one- to four-column layouts
* WooCommerce-ready styling for your online store
* Bundled Inter and Inter Tight fonts (loaded locally, no external requests)
* Translation-ready and WPML-ready (wpml-config.xml included)
* Clean, valid, SEO-friendly code

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the "Add New" button.
2. Click "Upload Theme" and "Choose File", then select the theme's .zip file. Click "Install Now".
3. Click "Activate" to use your new theme right away.
4. Theme options are available via Appearance > Customize.

== Frequently Asked Questions ==

= Does the free version require any plugin? =

No. Flexify works as a standalone theme. Elementor and ThemeREX Addons are optional and are recommended only if you want to use the front-page builder sections and Elementor templates.

= Where is the documentation? =

The theme documentation is available at https://doc.themerex.net/flexify/

= What does the Pro version add? =

The Pro version adds 200+ ready-made demo websites with 1-click import, 500+ Elementor blocks and templates, the headers and footers builder, advanced plugin integrations, AI features, and premium support. See https://themerex.net/downloads/flexify-100-elementor-wordpress-theme/

= Does the theme collect any user data? =

No. The theme does not collect, store, or transmit any user data. Fonts are bundled locally and no external requests are made by the theme itself.
